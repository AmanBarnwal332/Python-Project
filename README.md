## Project Overview

This project contains two Python applications developed to practice fundamental programming concepts, including loops, conditional statements, dictionaries, lists, user input, and basic data management.

### Project 1: ATM Simulator

The ATM Simulator is a menu-driven program that simulates basic ATM operations.

**Features:**
- PIN verification with a maximum of three attempts.
- Displays the current account balance.
- Allows users to deposit money.
- Allows users to withdraw money while checking the available balance.
- Records deposits and withdrawals in a transaction history.
- Displays transaction history when the user exits.

**Initial Settings:**
- PIN: `1234`
- Initial balance: `10000`

**File:** `pythonpro1.py`

### Project 2: Student Marks Manager

The Student Marks Manager stores student marks and calculates their academic performance.

**Features:**
- Stores student names and marks using a dictionary.
- Calculates average marks and rounds them to two decimal places.
- Assigns grades based on average marks.
- Identifies the student with the highest average.
- Allows users to add new students.
- Prevents duplicate student names.
- Provides a menu to view students, show the topper, and exit.

**Grading System:**

| Average Marks | Grade |
|---|---|
| 85 and above | A |
| 70 to below 85 | B |
| 50 to below 70 | C |
| Below 50 | F |

**File:** `pythonpro2.py`
